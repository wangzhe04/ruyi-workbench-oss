# 安全检查

请对当前改动做聚焦安全审查：

1. 查看差异，三处都要看：`git_status`（未跟踪的新文件显示为 `??`，整份读）、`git_diff`（未暂存）和带 `staged: true` 的 `git_diff`（已暂存；不带时这一侧会被静默漏掉）。识别信任边界、外部输入、文件路径、命令执行、网络请求和密钥处理。
2. 运行本地安全扫描信号（`code_review_scan`），但必须阅读命中代码后才能形成结论。
3. 优先检查注入、路径穿越、SSRF、XSS、越权、敏感信息泄露和不安全默认值。
4. 每个发现给出触发条件、影响、文件与行号、最小修复及验证办法。
5. 将“已确认缺陷”和“加固建议”分开；没有实质问题时明确说明残余风险。

上面点名的是如意工作台 MCP 工具（Claude Code 里叫 `mcp__ruyi__<名>`）；没有这些工具时用等价的 `git status --short`、`git diff`、`git diff --cached` 与 Grep、Read。

默认只审查，不修改文件。
