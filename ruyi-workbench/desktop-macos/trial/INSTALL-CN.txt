如意工作台 Mac 本地／内部试用版

本包仅面向可信来源的本地使用和小范围内部试用，使用 ad-hoc 签名，没有 Developer ID，也没有 Apple 公证。校验值只能核对文件一致性，不能代替发布者身份认证。

安装
1. 核对发送方提供的 DMG SHA256；可用系统“终端”执行 shasum -a 256 后将 DMG 拖入窗口。
2. 双击 DMG。将 Ruyi.app 拖入“应用程序”；没有该目录写入权限时，可复制到个人主目录下的 Applications 文件夹（~/Applications）。
3. 如目标位置已有 Ruyi.app，先退出运行中的如意并保留旧包。本轮安装测试只覆盖新位置安装；整包升级、回退和数据恢复另行验收。
4. 安装复制结束后推出 DMG，再从安装位置打开 Ruyi.app。后续运行无需挂载 DMG，也不需要预先安装 Node、Python、Homebrew 或 Xcode。

首次启动
从网络下载或经部分传输软件接收的包可能被 Gatekeeper 拦截。确认来源可信后，按系统提示到“系统设置 → 隐私与安全性”查看是否提供“仍要打开”，再确认打开。组织设备策略可能禁止手动允许，此时由设备管理员按组织规定处理。
此过程不要求关闭 Gatekeeper、SIP 或全局安全策略；本包没有提供绕过安全检查的脚本。若系统报告文件已损坏，先核对 SHA256 并重新获取包。

权限和数据
屏幕录制、辅助功能、麦克风等权限按功能需要由用户在系统设置中授予，授权并不随安装包传递。拒绝时对应功能可能不可用；允许后按提示重新启动如意。不得以界面可打开代替这些功能已经获得授权。
本试用包保留当前开发应用标识。同一数据目录只运行一个如意实例，换构建后系统可能重新请求权限或钥匙串访问；稳定升级授权仍待后续验收。
业务数据保存在 ~/.ruyi-workbench 或你显式配置的 RUYI_HOME，程序包保持只读。移走 Ruyi.app 不会自动删除业务数据；保留数据的卸载只需先退出如意，再将安装的 Ruyi.app 移到废纸篓。

Full 与 Slim
Full 随附独立 Python、ACC、Office/图表/视觉依赖和 Chromium；浏览器设置选择 bundled 才使用随包浏览器。
Slim 提供基础工作台、Node、搜索及原生 helper，不随附 Python/ACC/Office/浏览器依赖。
两种包都不含官方 Agent CLI、Git 或模型权重。需要自行配置模型服务；本地／内网模型可离线使用，云 API 需要联网。

验证边界
目前验证环境为 macOS27.0.1 arm64 的当前账号隔离目录，不等于干净标准用户或没有开发工具的另一台 Mac。macOS14 是最低目标，实际运行仍待验。正式签名、公证、真实下载来源首次允许、钥匙串/系统权限恢复、升级回退，以及 P5 原未验范围均不因这份试用说明计为通过。
