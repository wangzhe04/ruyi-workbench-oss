## 1. 总策略

**一句话:换容器,不换引擎;投影先行,壳层渐进置换;契约先于 UI;每一步都有退路。**

- 执行资产(双引擎/工具/权限/检查点/审计/技能/记忆/离线存储)**零重写**——概念稿 §8.3 非目标第 2 条冻结。
- 新壳层全部状态来自 EC-E 已交付的持久化投影,**禁止前端拼装散装端点、禁止模型文案猜状态**(go 条件 #1/#5,no-go 触发器 #1/#3)。
- **契约先于 UI**(v2 新增):跨壳共享的不是「现有 REST API」这个现实,而是**统一领域契约**——P1 先冻结 `POST /api/interventions/:id/decision`(统一 action/idempotencyKey/错误码/过期语义),内部适配现有四套异构执行路径;P3 的 UI 只接契约,不碰四个端点。
- 双壳并存期:新功能只实现一个业务入口,经共享 command 层被两壳调用,**禁止两套业务状态**(§9.2)。
- 每波沿用本仓纪律:红绿双证 e2e、冻树全量门、主会话亲跑验收、src/ 改动主树串行(server.js 11k+ 行单文件不派并行 worktree)。

### 2.4 每波 Definition of Done(v2 新增——安全/i18n/a11y 不再集中到 P2/P4 末尾)

每一波(自第74波起)提交前必须同时满足:
1. 新交互键盘可达、焦点可见、读屏有名词(ARIA),双语键齐全(locale 扁平键纪律,无 [key] 渲染);
2. 新写路径带威胁标注:权限边界、token 鉴权、跨会话归属校验;**批准类动作必须带上下文、作用域、过期状态与二次确认策略**;
3. 红绿双证 e2e + 冻树全量门绿 + 主会话亲跑(既有纪律,成文固化);
4. 经典壳层零回归(P2 起);
5. 新字段/新端点在 schema 文书内有对应条目(P1 出门后)。

第80/86波的「走查/硬化」因此是**终审**而非第一次补齐——终审仍抓出系统性缺失 = 该波 DoD 执行失实,记账。

## 3. 门语义三分与北极星指标(v2 新增)

评审指出:第56波 31 条 e2e 证明的是**数据正确**,不能证明可理解性与旅程改善。门重新分层:

| 门 | 含义 | 现状 |
|---|---|---|
| **Data Ready** | 投影/契约/幂等/重启语义有 e2e 钉死 | ✅ 已基本通过(EC-E + 56 波) |
| **Product Ready** | 真实渲染 + **真实操作**(回滚按钮真点、决策真提交、旧数据双壳完整交互)+ 可用性验证 | P2 Preview 前必须达到 |
| **Release Ready** | 安全、迁移、离线包、长期数据压力 | P4 |

**北极星可观测指标**(P2 起随性能门同测,本机 scripted 测量即可,不引遥测):
- 回来后定位任务变化所需时间(目标:从打开到说出「变了什么」≤10s,靠 79 波回来摘要);
- 发现待决事项时间(目标:从任意视图 ≤2 击 ≤5s);
- 回滚能力误解率(可用性走查中用户对可回滚/部分恢复/不可逆的判断正确率,目标 ≥90%);
- 离场任务成功恢复率(重启/刷新后续办不丢状态,目标 100%,e2e 可证)。

## 4. 波次规划 v2(P0✅ → P4,自第74波起,3.0 交付线 15 波)

### P1 · 领域基础收尾 + 契约与规模门(第74–75b波)

**第74波 · schema 冻结文书 + 威胁模型 + 类型全集**
- 交付:`docs/PRETENDER-SCHEMA.md`——Mission projection / Intervention 字段级冻结(字段名、类型、权威来源、可变性)、事件语义、幂等规则、过期规则、schema version 与迁移契约;missionId 按 D1=方案 B 成文(派生规则、与 sessionId 的关系、1:N 扩展语义标注 3.1);**Intervention 类型枚举一次冻结** `permission|question|plan|pool|conflict|stall|budget`,显式标注 3.0 有生产者(前四类)vs 保留位(后三类,无生产者不暗示可用);**Mission 控制面语义**(暂停/继续/停止/重试/人工接管,逐动作界定作用于当前回合/当前 Run/整张 Mission);**跨会话决策 threat model**(C3 前置):伪造/重放/跨会话越权/过期竞态/不可送达五类威胁与对策。
- 退出条件:文书覆盖 §9 两张 schema 全字段;现有 e2e 断言与文书逐条可对照;threat model 每条威胁有对应现有机制或 75/81 波对策落点。
- 风险:低(纯文书)。

**第75波 · missionId 落地 + C4 竞态修复 + 统一决策契约**
- 交付:
  - **missionId 派生**(方案 B):session 主键与文件布局不动;新会话 `missionId=sessionId` 派生写入;`normalizeSession` 存量只读派生不回写;`/api/missions`、`/api/interventions` 对外标识从第一天以 missionId 命名;
  - **C4 竞态修复**:provider 回合内 mission 写与回合收尾盖回的定序,红绿双证;
  - **统一决策契约** `POST /api/interventions/:id/decision`:统一 action(approve/reject/answer/cancel)/idempotencyKey/expectedVersion/错误码(**重复决策全类型 409**、过期 410、不存在 404、不可送达 409-with-reason)/审计字段;内部适配现有四套执行路径,**旧端点双壳期保留有效**(契约是门面,不是替换)。
- 退出条件:契约 e2e——四类 Intervention 经统一入口决策,重复提交统一 409 不重复执行;旧端点回归零红;missionId 三处一致;C4 绿。
- 风险:中高。契约适配触碰四个决策路径,主树串行;幂等语义以 71/71b 既有测试为基线不得回退。

**第75b波 · 规模门(v2 新增)**
- 交付:Mission/Intervention **可重建物化索引**(派生索引,权威源仍是原文件,索引损坏可全量重建);列表端点 cursor 分页 + projection revision/ETag;Intervention NDJSON 压缩与损坏尾行恢复;**大数据集压力门**:数百 Mission、数万 Intervention 行、十万级 usage/event 行下,列表/详情/全局收件箱冷启动与热缓存延迟分别测量并钉预算(具体数值本波实测后成文);低配模拟(限 CPU/IO)复测。
- 退出条件:压力门全绿;索引重建 e2e(删索引→自动重建→结果与全量扫描一致);坏尾 NDJSON 恢复 e2e。
- 风险:中。索引是缓存不是第二状态机——重建一致性断言是核心防线。

**P1 出门闸**:schema 冻结 + missionId 一致 + C4 关闭 + **统一契约四类全通** + **规模门绿**。此后任何 UI 不得引入文书外字段。
