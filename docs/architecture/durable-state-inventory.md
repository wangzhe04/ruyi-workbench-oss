## Scope notes

- NDJSON append logs, session v2, compressed binary snapshots and exit-time synchronous writes retain their dedicated protocols.
- External files are merged or consumed without claiming ownership; workbench sidecars track only fields it owns.
- Regenerable caches may treat invalid data as a miss when authoritative inputs can rebuild them.
- `context-calibration` is the 103c full-lifecycle pilot and exercises schema, sanitize, quarantine, capacity, serialized atomic write, cache invalidation and recovery.
