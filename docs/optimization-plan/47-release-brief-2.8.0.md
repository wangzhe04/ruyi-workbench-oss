## 路线图四问（先回答这四句，其余是证据）

**① 解决谁的什么问题？**
一个人在自己的 Windows 机器上用多家模型干活。2.8.0 解决四件他每天会撞到的事：
**交给时钟的活会按时跑**（定时任务）、**工作台说的话能追溯到谁说的**（验收来源、委托书、回执驱动）、
**喊停就是喊停 / 失败说得出原因**（125 波）、**长会话不再把刚才那段丢掉**（压缩三开关默认开）。
另加一件能力项：**能用说话代替打字**（语音输入）。

**② 明确不做什么？**
**不正名 3.0**（2026-09-18 用户拍板：2.8.0 以 Escapade 2.x 发布；3.0 在偿债波＋128+ 全部既定项＋P4 收尾硬门完成后再发，见路线图 Pretender 行）；不做多用户与权限体系；不做云端同步；不做新壳（两壳长期并存，[22 号文 §8](22-agent-soc-microarchitecture.md) 的退出时钟已于 2026-09-15 由用户拍板作废）；
不在本版收 URL 准入（`audioBaseUrl`／`baseUrl` 仍不拒私网／回环，见 §4 未完成项 ④）；
不修「默认值被冻在盘上」这个结构性缺陷（§3 ②）；不为 111a／111c 翻默认（§2 表）。

**③ 怎样证明完成？**
六类通用发布门（§4）＋ 一条硬规矩：**默认关的开关不算已交付收益**（22 号文 §8 第 2 项原话）。
本版有真模型读数的是 111 五个开关（[107-E1 读数](107-e1-readings.json)，配对各 6 次、¥11.96、零无效样本）
与管家代批（[45 号文 §9.6](45-wave-127-service-catalog-and-voice.md)）；其余产品功能的证据是 e2e ＋ 人工走查，**证据只有假桩的一律打 ⚠**。

**④ 失败后怎样恢复？**
见 §3。一句话：**升级前备份 `config.json` 与 `steward/`**；退回 2.7.0 会静默抹字段（§3 ③），
所以「能退回」这件事本身要靠备份，不靠版本兼容。

## 3. 迁移、回退、发布后扩围（22 号文 §8 第 3 项）

**① 升级会自动获得的（照实点名，CHANGELOG 已逐条写）**
代批开、定时任务开、新线程跟随上次引擎，**外加 T1 的三个压缩开关**。

**② 三个压缩开关的迁移是本版唯一会改写盘上已有值的一处**
`CONFIG_SCHEMA` **11 → 12**，`incomingConfigSchema < 12` 时把这三个键里的 `false` 改成 `true`。
**为什么必须这么做**：`normalizeConfig` 是 `{ ...defaultConfig(), ...raw }`（raw 永远赢），而 `readConfig`
只要 `changed` 为真就把**整份合并配置**落盘（`01-config.js:1577`）——历次迁移写盘已把这些键冻成 `false`，
光翻默认对所有存量安装是**空操作**（主会话用 2.7.0 构建产物实测确认）。
**升级之后用户自己关掉的（schema 已是 12）永远不会被再打开**，有常驻单测守（`unit/config-schema-12-migration.test.js`，5 组）。
**结构性缺陷记债不修**：此后每一次改默认对存量安装仍然无效；根治要改写盘策略（只落用户真正改过的键），面太大。

**③ 退回 2.7.0 会静默抹数据 —— 这条是本版最该让人看见的风险**
2.7.0 的 `sanitizeProvider` 把 `models[]` 重建成 `{id,label}`，**首读即回写**，抹掉 `models[].caps`／`audioBaseUrl`／`hiddenModels`（新增的 `asrProtocol` 同理）；
2.7.0 的管家记忆规范化丢 `expiresAt`／`scope`，下一次写就整库回写。`.prev` 只留一代。
⇒ **降级前必须备份 `config.json` 与 `steward/`**（已写进管理员手册）。
**未实测**：三个压缩开关的键留在盘上被 2.7.0 遇到会怎样（2.7.0 不认识也不读它们，推断无害）→ 由 ⑧ P1 降级演练补。

**④ 回滚（不降版本）**：覆盖升级包配 `Manage-Overlay.ps1 apply/rollback`；②P0 已把 `resources/playbooks` 与 `app/public/css` 补进载荷并配锁（此前漏装，老用户拿不到 127 波改的 13 个模板）。

**⑤ 发布后扩围条件**：111a 要先换一条能说清「护住尾部观测」收益的指标；111c 要先清掉摘要自带答案这个污染（需要换设计）；混元 ASR 要先找到文档化的转写路径。

**B. 记债不修**
1. 被否决的记忆**换个说法就能写回来**。
