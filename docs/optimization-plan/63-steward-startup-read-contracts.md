## 本批范围

1. 同一数据目录只允许一个 serve 实例执行恢复、迁移、索引失效与配置同步。第二实例明确拒绝，不取消活实例的待决、不覆盖握手、不自动结束占口服务。不同数据目录可同时运行；MCP 子进程不取得服务独占权。

## 启动所有权设计

采用 Node 内建 IPC 的操作系统独占监听句柄，避免把可过期的磁盘文件当锁。标识由数据根真实路径生成，Windows 归一大小写和目录联接；Windows 使用命名管道，支持的 Linux 使用抽象 Unix socket。其他 POSIX 环境使用普通 Unix socket时须明确残留处理边界，不在不确定时删除可能属于活服务的句柄。

获取失败在业务恢复及启动错误落盘之前返回明确错误。旧版本没有新锁时，以既有 runtime 的 PID 作保守兼容检查：活进程或无法证明已退出时拒绝，绝不以 PID 身份推断为理由杀进程。端口占用只触发端口顺延，取消自动接管活服务的生产调用。

释放只关闭本次捕获的句柄；重复释放、旧所有者释放不能影响新实例。Windows 命名管道与 Linux 抽象 socket 持有到操作系统完成进程退出，避免退出保存期间先释放锁。普通 socket 的正常退出清理注册在已有同步保存之后；启动失败则保守持有到进程退出。旧目录迁移在所有权保护后执行；需要同时保护旧/新路径时按确定顺序获取，并核对迁移后所有数据路径消费者，避免目录联接失败时写回旧根。

验收必须包括：同根双端口、并发竞争、Windows 大小写/目录联接别名、崩溃后恢复、旧 runtime 与 PID 复用的保守行为、重复释放、MCP 初始化，以及失败启动前后 pending/runtime 内容不变。更新旧 port-fallback 中“杀活 A 接管”的过时预期，保留无关占口进程不受影响的断言。

## 轻量读取契约设计

复用 `steward_web_search/file_read/thread_artifact_read` 等已有只读入口及其权限、路径、SSRF 和污染检查。不给管家新增写文件能力，不弱化外部内容污染规则；读取结果是参考材料，不是授权。

固定五类旅程：已有状态、材料解释、多材料报告、修改文件、已有任务续问。离线测试必须经生产管家循环真正调用工具，检查下一请求中的回执、最终落盘及是否实际创建/继续线程；不能用手工 ctx 代替调用链。缺材料与污染后动作另做反向验证。提示预算不放宽。

语义验证使用本机已配置 Ollama，固定模型与参数，旧/新各五题，最多十次首响应请求（失败也计数），单次有界超时。只评估首轮工具路由，不执行模型提出的副作用，不把它等同完整任务成功；记录样本量、失败/unknown、延迟与 token。端点不可用时如实报告，不自动切换付费服务。本批不新增记忆注入，自动补召回仍受 62 号方案采用门约束。

## 验收记录

验收环境：Windows，Node.js 24.14.1。功能由两个 `gpt-6.1-sol` 子 agent 实现，主会话审查设计、边界与反向证据，并独立复跑生产路径测试。

- **启动保护**：同根双端口、并发竞争、Windows 大小写与 junction 别名、崩溃后恢复、旧 runtime 活 PID 拒绝、MCP 初始化通过。被拒实例不改 pending、runtime 或启动错误记录。
- **退出时序**：在临时夹具的退出保存窗口移除 runtime PID 兼容检查，第二 serve 仍被 IPC 独占拒绝；将临时构建改回“退出时先释放”后，该断言单独失败。反向构建已删除，正式构建未保留变异。
- **迁移与端口回归**：主会话独立复跑 `data-root-migration.e2e.js`、`port-fallback.e2e.js` 全过，涵盖 junction 创建失败后动态 store 路径仍指向新根，旧目录不被重建，以及占口进程不被结束。
- **读取与派单**：主会话独立复跑 `steward-read-routing.e2e.js` 全过。经真实服务与生产管家循环，用固定假 provider 验证工具回执进入下一请求、线程真实创建/续办、原话与工作区保留、结果落盘，并验证工作区、SSRF 与污染写动作拦截。它证明调用链和契约，不代表真实模型一定选对工具。
- **提示预算**：中文 1117、英文 1249，仍在既有 1250 门限内；42 个工具数量不变。未新增记忆注入，既有记忆召回精度与注入回归通过。
- **完整单测与静态门**：主会话运行 `run-all.js --fast --parallel 4`，1846 项单测中 1820 通过、26 跳过、0 失败；80 个静态件首跑 78 通过、2 失败、0 flaky。失败定位为新增测试未同步的清理数量锁及夹具环境继承的静态契约；调整后主会话独立复跑这两件全部通过，保留全部隔离与清理断言，未改产品源码或放宽扫描器。修正后相关四件生产 e2e 再跑全部通过；没有把首跑退出码 1 改写为单次全绿。
- **构建与清册**：最终 `build.js --check` 新鲜，模块依赖图、路由、架构及持久化清册一致；没有增加依赖环或放宽 policy。全仓语法检查 964 个文件、0 失败。README 与 facts 同步为 504 件 e2e、232 组单测文件；这是仓库数量，不表示本批运行过全部 504 件。
