# 3.1 全工具转译与按档位启停补充

日期：2026-10-19—20。补充 [81 号设计](81-privacy-vault-and-tokenization-31.md)；发生冲突时以本补充为准。用户追加要求是：模型使用代号调用工具应正常运行，覆盖全部登记工具；默认关闭、不启用加密时不运行扫描和加解密。最终执行结果另见 [82 号实施记录](82-privacy-31-implementation.md)，本文不代替通过报告。

## 开关与档位

| 状态 | 请求／工具路径 | 存储与开销 |
| --- | --- | --- |
| 脱敏关闭、凭据加密关闭（新安装默认） | 原请求、原返回、原参数对象；不创建代号、不解析转译参数、不启动规则 worker | 不创建映射／主密钥，不自动迁移明文凭据 |
| 仅凭据加密开启 | 工具保持原路径；本地配置凭据在读写时保护 | 只初始化明确启用的凭据存储，不进行模型内容脱敏 |
| Basic | 凭据识别及用户规则；已识别值在本 scope 精确复用 | 不启用个人、内部与技术信息规则；无 regex 不启动 worker |
| Enhanced | Basic 加个人隐私识别 | 同 scope 学习及有界源内容投影 |
| Strict | Enhanced 加内部保密内容识别 | 保持资源上限，不依靠无限重扫提升覆盖 |
| 技术信息开关 | 独立控制私网地址、路径等技术信息 | 关闭时不执行这组规则 |

已有明确启用的加密配置和引用继续兼容，不能因为新默认值擅自解密。脱敏映射需要本地加密，设置页须明确选择加密后再开启脱敏；旧版脱敏开启却缺少该选择的配置暂停外发，等待用户核对。关闭加密只允许在脱敏关闭后明确确认“凭据将以明文保存”；配置原子提交失败仍保留原状态与可解锁凭据。旧 vault 不因关闭而删除，以保留已有备份的恢复能力。

工具与模型数据通路关闭时，在枚举凭据、构造数据识别器、解析转译参数、规则 worker 和映射持久化前返回。开启后无敏感命中的新 scope 不创建主密钥或映射；已落盘且版本未变的映射不重复 AES 加密和写盘。尚未完成的同版本持久化共享同一 promise，失败不能提前发送或记成已保存。

上述保证针对数据处理通路。配置读取仍校验规则配置，恢复票据使用进程内随机值做一致性认证；这些步骤不扫描用户或工具正文，不创建 DPAPI 主密钥、vault 或代号映射。用户主动试验或保存规则时仍可校验自定义正则；配置恢复故障仍会暂停外发，不能借关闭开关绕过恢复确认。

## 通用工具协议

脱敏负责模型侧数据转译，工具仍执行原有的权限、工作区、文件与网络检查。它不替代这些权限，也不额外给代理增加执行能力。

1. 模型历史保留代号。主回合和子任务从实际原生注册表、本轮托管 MCP 路由建立宿主能力；不能从模型输入里的 `registered` 等字段取得能力。
2. 统一执行副本对登记工具的嵌套字符串值、数组和字典 key 逆转译，不再按工具名或参数名列出文件工具小白名单。字典还原发生碰撞时拒绝；未知、过期、撤销、跨 scope 的引用继续拒绝。
3. `tool_invoke_*` 按真实 `name/arguments` 及兼容壳归一化，检查最终目标登记后才还原。原输入树和代理递归共用深度、节点、文本预算。MCP 路由只承认自身属性及完整 server/tool 记录，原型链属性不能成为登记工具。
4. 登记工具可在用户任务所需的参数中使用凭据代号，包括命令、连接器及远程工具。宿主明确授权执行副本的用途；权限面看到真实参数。没有登记能力的内部兼容调用保留更保守的旧规则，不能借此调用未知工具。
5. 工具运行后，返回给模型的副本重新经过规则与 scope 已知值识别；本地结果及真实副作用按工具语义保留。执行参数的还原不修改模型原调用或历史。

全工具合同从真实注册表生成名字集合，新增登记项自动纳入参数转译测试。隔离 fake recipient 证明通用运输合同，不能宣称已逐个执行全部工具的真实副作用。另以实际文件、搜索／画像／差异、命令、网络、托管 MCP、管家与子任务测试覆盖代表实现。

## 源内容投影

对完整 JSON 字段识别后再按行或字符截片，会丢失字段语义，甚至只留下敏感值的一半。原来用整类禁用避免这类泄漏的方式改为内部源适配：

- 只使用本次工具原本获准读取的完整 snapshot，先识别再按原坐标生成显示片段；搜索匹配仍基于真实内容，不因代号替换改变查找语义。
- 窗口触及敏感替换跨度时扩展至整个代号，不能切出半个原值或半个代号。文件编辑仍可逆转译为原始拼写，包含转义、重复键与长整数字面量。
- 搜索 worker 返回与实际匹配同一次读取的 snapshot；Git 比较原 blob／工作树哈希和行内容，避免第二次读取的内容冒充原结果。差异的 hunk section context 也属于源内容，不能保留被 Git 截短的敏感前缀。
- 只有宿主登记的结果容器对象、具体 JSON Pointer 叶值和精确文本具有来源 proof。proof 由 WeakMap 保存，绑定 scope 和不可伪造 view；允许多 source 显式联合。普通 MCP JSON、clone、未登记 metadata 和伪造 view 不能获得信任。
- 证明同时检查 JSON 解码后的引用归属。后出现字段或别的源学习到新敏感值时，旧 view 必须重新证明覆盖；未覆盖的旧片段拒绝，不把已知完整值的 exact 检查当成半截值保护。

当前限额：每次 scope 回合最多 128 个源 snapshot、累计 8MiB、单源 1MiB；源匹配共享 32MiB 比较工作与命中上限。越限、内容变化或证明失效给固定错误，不发送未检查尾部，也不自动扩大文件读取权限。

## 验收与边界

- 关闭时校验对象身份、参数 getter／注册回调不触发，脱敏边界的数据识别、参数解析、规则 worker、映射与主密钥包装为零；开启时记录匹配、密文写次数及代表输入耗时，避免用模型网络时间掩盖本地开销。
- 每档位测试真实登记工具的嵌套参数、凭据、字典 key、代理与 MCP；权限拒绝必须发生在 handler 前，且检查真实参数。模型请求不得出现哨兵原文。
- 源投影需包括部分字符／跨行／非 ASCII、分组搜索、画像完整样例、Git hunk context、proof clone／篡改／晚学习与编码引用反例。
- 命令与任意 MCP 可对数据做编码、截断或任意语义转换；本地识别不能保证还原这些未知变换。自定义规则与已知值匹配仍生效，不能声称自动理解所有第三方程序的保密语义。
- 数字／布尔／对象敏感值、二进制和不透明签名内容沿用明确的能力限制，不能把类型错误或无法检查的媒体记成已保护。多媒体外发策略等待用户对独立开关的选择；当前没有默认放行原媒体。
- 稳定产物的真实 DeepSeek 扩展矩阵已完整通过 20 个场景；Windows 全量、成品 ZIP 与升级结果以 [82 号实施记录](82-privacy-31-implementation.md) 的最终完成项为准，早期成功只证明对应 SHA 的候选。

## 本地档位基准

`dev-harness/privacy-31/profile-overhead.js` 使用合成凭据包装与真实 AES、约 3136 字符输入，预热一次后每档重复 100 次；不访问网络或用户配置。一次迭代包含请求、工具返回与参数处理。2026-10-19 Windows / Node 24.14.0 实测：

| 档位 | 中位 ms | P95 ms | 整档密文写入 | 正则 worker 扫描 |
| --- | ---: | ---: | ---: | ---: |
| Off | 0.0019 | 0.0094 | 0 | 0 |
| Basic | 1.9529 | 3.4145 | 1 | 0 |
| Enhanced | 2.4569 | 5.4990 | 1 | 0 |
| Strict | 3.4972 | 6.9586 | 1 | 0 |

报告 `%TEMP%/ruyi-privacy-profile-overhead-20261019.json` 记录源 SHA。该实验用于比较本地档位开销，排除模型网络延迟、真实 DPAPI 冷启动、规则 worker 和大型来源扫描，不作为这些场景的耗时承诺。普通关闭路径另有 getter／对象身份反例验证，不能仅凭微基准推断没有加密调用。

2026-10-20 ux10 加入常见一层编码识别后，同口径合成微基准：Off 中位 0.0016 ms／P95 0.0055 ms；Basic 3.3026／5.7640 ms；Enhanced 5.7861／8.0895 ms；Strict 5.6070／6.7210 ms。Off 整档密文写入与 worker 调用均为 0；其余每档稳定映射只写 1 次，无自定义 regex 时 worker 调用仍为 0。结果受本机并行构建／测试负载影响，保存在 ux10/validation/profile-overhead.json，不是大型文件或真实 DPAPI 的时延保证。默认关闭仍直接绕过识别、映射、工具参数加解密；开启后的编码识别不递归，并按候选和解码文本预算限制工作量。

Windows 启动另测冷路径：首次默认配置中的同步 Claude／Kimi 发现曾占约 1.73 秒，与 DPAPI 无关。真实 serve 启动改用已有异步探测，绑定后配置消费与恢复等待完整发现，显式路径与验证失败回退保持。89132 稳定产物实测启动健康响应 354ms、探测期间 2ms，原 2500／800ms 预算不变；普通非 serve 的首次配置读取契约保持。

配置丢失时不能将“新安装默认关闭”当成用户曾确认关闭。恢复选择按引用、真实布尔选择、独立保存的成功读写原语与未知非空 vault 保守回退判断；未知旧库继续加密并暂停外发，可信明文 prev 可继续关闭。真正新安装不创建 vault。恢复包导入凭据也不会代替策略确认，用户确认后才恢复模型调用。
