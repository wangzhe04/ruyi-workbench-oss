## §1 口径

- **版本号**：`3.0.0-preview.1`（package.json／00-boot.js／facts.json 三角一致），标签 `v3.0.0-preview.1`，GitHub 上以 **pre-release** 发布。版本号只作字符串用（全仓无 semver 比较；覆盖包是「恰好等于」闸，本版不发覆盖包），`meta-guard` 取主次版本得 `3.0`。
- **品牌冻结**（路线图 :19、22 号文 §8）：用户这次要求发 3.0 预览，等于对**预览版号**放开冻结；界面上会显示 `3.0.0-preview.1`。正式 3.0 批准点的其余纪律不变。
- **范围**：自 v2.6.2（最后一个 GitHub Release）以来的全部变化。`v2.7.0`／`v2.8.0` 只打了标签、没发过 Release（2026-09-24 查 GitHub Releases API：最新是 v2.6.2），随本预览一并发布；CHANGELOG 的 2.8.0 节「发布日待填」据此补成「2026-09-19 打标签、未单独发 Release」。
- **不宣告**：50 号文三组门走完、人因验证完成、安全红队终审完成。

## §6 正式 3.0 前还剩什么

1. **人工**：安全红队终审（重点：管家代批、外界内容污染、跨线程权限、后台停止路由）；真读屏与键盘走查覆盖最近的组件（Mermaid 灯箱、等你处理队列、后台任务条）；Full 包在真实桌面双击启动器。
2. **决策**：E02 收口或移出；候选池那句话的效力；路线图 :81「跳过正式人因验证」是否在 3.0 批准点重新执行或记录豁免。
3. **产品小项**（本轮看到、未做）：ASR「添加」一行不能再自由填目录里没有的模型名（要先加进服务商模型清单再选）——是否加回「其他…」自由输入，是产品选择；`settings.asr.addPlaceholder` 已无引用。
4. 预览版之后的任何改动，按 CHANGELOG 顶部注释并进正式 3.0 一节。
