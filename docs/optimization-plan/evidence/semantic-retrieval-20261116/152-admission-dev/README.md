# 152 Q1 开发集准入回放（2026-11-27）

首轮开发集筛选得到的候选为**字段最高余弦 ≥ 0.65，且高于该查询对 32 条中性参照文本的平均余弦至少 0.10**。12 字段小池沿用此候选。产品策略、worker、自动注入配置均未据此变更。新冻结题集的作者和验收口径仍待 D6 确认。

## 数据与计分

使用已消费的 V7 R3（SHA-256 为 `63a03095d788dbf4cb0275037145cb6584cb971501f42ccd9999456d55e89dc3`），含 96 个文档、324 个窗口及 268 个查询。真实打包 Gemma worker 对完整的文档和查询编码，所有输入均未截断。沿用原导出器的 96/80 UTF-16 窗口与逐文档最高余弦。重新导出的既有 top-5 排名 JSON 与历史 encoder-gemma.json 的 SHA-256 相同。另用 128 个公开合成记忆头：8 个服务各有 5 种部署规则，另外 88 个为场所规则。40 个查询各标注对应的服务和规则，16 个中英日常短消息均为无答案。12 字段压力样本从同一库取 5 个同一服务的规则与 7 个场所字段，复用相应的 5 个正例与 16 个短消息，不计作独立观测。参照集含固定的 16 条中文和 16 条英文中性描述。记忆池是模板生成的数据，每个字段恰好一个窗口，不代表个人记忆库和长字段的分布。

每个规则先对字段取窗口最高分，再按分数降序取前 5。正例计算首位命中、前五命中与 MRR@5，漏检的倒数排名记零。对无答案题，只要放行任一字段即记一次误报；缺字段、缺数字与实体错配同样按无答案处理。包括 3 个绝对阈值、9 个池内 MAD 参数组合、9 个参照组合、27 个联合组合，共 48 组。参照与 MAD 规则都设绝对下限。池内标准化使用 1.4826 × MAD，MAD 为零时 z 取零。
