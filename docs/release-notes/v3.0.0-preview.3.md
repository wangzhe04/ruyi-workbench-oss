## Preview 3 新增 · New in Preview 3

1. **权限回到五档，新装默认「智能自动」。** 「全自动」回到界面，有自己的确认与红色警示；智能自动下管家被即时叫醒、能替你批更多非底线动作、必须表态，你正看着的提问它不插手。全新安装出厂档改为智能自动，已有配置不变。工作流里 Claude 引擎的子代理按权限档收紧，设置里的「能力总闸」现在也管内置桌面控制（ACC）的同类工具。
2. **模型干活更顺手。** 每条消息带一行本地时间；新增只属于本对话的草稿本（压缩、重启后都还在）；你在界面撤销文件改动后模型下一轮会知道，并能查看哪些改动可撤销；找工具时直接拿到完整参数，选错风险档的代理自动改道；Playbook 步骤与技能清单可读；记忆提议一次可带三条，仍由你逐条确认；工具装载按提示缓存来，少断缓存。
3. **语音词库。** 个人词与 472 条内置常用词接进实时识别、句尾重听与大模型改字；从你发送前的手改里学会常被听错的词。
4. **Anthropic Messages 协议。** 模型服务商新增第三种协议，官方 API 与兼容网关都能直接接，已适配 Claude Opus 5.5 / Sonnet 5.5。
5. **Mermaid 全面走查。** 亮暗两套配色、模型常写错的写法自动修好再画、各图种暗色可读、宽图横向滚动、多图回复画完仍贴底。
6. **更稳、更快。** 体验走查、两轮代码走查、整仓审计与两轮工具走查；四批架构偿债；长会话性能四轮；英文系统上 PowerShell 的中文不再变成问号；随包 offline-toolkit 插件终于能装进 Claude Code。

1. **Five permission levels again, Smart auto by default for new installs.** Fully automatic is back with its own confirmation and red warning; under Smart auto the steward wakes immediately, may approve more non-floor actions, must take a position, and stays out of prompts you are looking at. Fresh installs now start in Smart auto; existing setups keep their mode. Claude-engine workflow sub-agents follow the permission level, and the capability switches now also cover the built-in desktop control (ACC).
2. **A model that works more smoothly.** Each message carries one line of local time; a per-conversation scratchpad survives compaction and restarts; undoing file changes in the UI is reported to the model on the next turn, and it can list which changes are undoable; tool search returns full parameter lists and wrong-tier proxy calls are rerouted; Playbook steps and the skill list are readable; memory proposals can carry three items, still confirmed one by one; tool loading follows the prompt cache.
3. **Voice vocabulary.** Your own terms plus 472 built-in ones feed live recognition, end-of-sentence re-listening and LLM correction, and frequently misheard words are learned from your edits before sending.
4. **Anthropic Messages protocol.** A third provider protocol for the official API and compatible gateways, adapted to Claude Opus 5.5 / Sonnet 5.5.
5. **Mermaid audit.** Light and dark palettes, automatic repair of common model-written mistakes, readable dark mode for every diagram type, horizontal scrolling for wide diagrams, and the chat stays at the bottom after several diagrams render.
6. **Steadier and faster.** UX walkthroughs, two code-review rounds, a whole-repo audit and two tool audits; four architecture-debt batches; four long-session performance rounds; Chinese PowerShell output no longer turns into question marks on English Windows; the bundled offline-toolkit plugin finally installs into Claude Code.

## 升级须知 · Upgrading

- **解到一个新目录**，不要用覆盖包跨版本升级；回退＝回到保留的旧目录（回退前备份配置与管家数据）。
- **数据目录改名**：`~/.win-claude-workbench` → `~/.ruyi-workbench`，首次启动自动搬过去，旧路径留一个指回来的目录联接。
- **MCP 名称改成 `ruyi`**：Claude Code／Kimi Code 里的如意工具名变成 `mcp__ruyi__*`，旧登记由 `install` 与安装脚本清掉；离线插件市场改名 `ruyi-offline`。
- **出厂权限档只对全新安装生效**：已有配置升级后仍是原来的档位（没存过档位的老配置钉回「每步都问」）；配置自动从 schema 13 迁移到 14。
- **Unzip into a new folder**; do not overlay across versions. To roll back, go back to the old folder (back up config and steward data first).
- **Data folder renamed**: `~/.win-claude-workbench` → `~/.ruyi-workbench`, moved on first start with a junction left at the old path.
- **MCP name is now `ruyi`**: Ruyi tools in Claude Code / Kimi Code are `mcp__ruyi__*`; `install` and the installer remove the old registration; the offline plugin marketplace is now `ruyi-offline`.
- **The new default mode applies to fresh installs only**: an upgraded setup keeps its mode (an old config that never saved one is pinned to Ask every step); config migrates from schema 13 to 14 automatically.

## 预览版的边界 · What this preview does not promise

- **还没做、正式版前要人来做的终验**：独立安全红队终审（写代码的人不给自己发合格证）；真读屏与人因走查；Full 包在真实桌面上双击启动器。
- 「本地工作台」指软件与数据放在你机器上；用云模型、在线检索、云语音时，必要内容仍会发给对应服务。
- 本地语音组件、本地模型需要另外安装（ruyi-toolbox），不在两个 zip 里。
- Human-only sign-offs still pending before 3.0 final: an independent security red-team review, real screen-reader and human-factors walkthroughs, and double-clicking the Full launcher on a real desktop.
- "Local workbench" means the software and data live on your machine; cloud models, web search and cloud speech still send the necessary content to those services.
- The local speech add-on and local models are installed separately (ruyi-toolbox) and are not in either zip.
