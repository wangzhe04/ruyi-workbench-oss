# 如意 Ruyi 3.0.1 · 2026-10-16

3.0.1 汇集自 3.0.0 以来已合入的修复与体验更新：长任务接续更可靠，班组协作更清楚，原生多媒体检查更完整。本版还公开 SWE-bench Pro V2 HARD-51（51 题困难子集）的 51 题实测摘要与官方组合对照。

## 本版更新

- **长会话能接着做。** 压缩后保留仍有效的任务约束、用户教过的操作流程和证据引用；跨会话回读与阅读任务的接续更可靠，减少反复重读与目标丢失。
- **班组协作更清楚。** 可发现当前活跃代理，明确续派已完成节点；收尾消息有投递回执，避免漏收和重复交付。协作信封保持有界，减少占用上下文。班组监控与工具箱导航更易用。
- **管家与会话更稳定。** 修复协议切换、新建会话、切换线程后的迟到响应覆盖和草稿丢失；删除会话会停止其后台代理，清理后不会被迟到写入重新生成运行记录。
- **多媒体检查与证据。** 新增原生图像及文档视觉读取、多媒体依赖探测与检查流程；同批图片先完整交给模型，再淘汰历史图片。验收报告区分可验证证据与自报结论。
- **编辑与定时任务修复。** JavaScript 语法检查遵循项目 CommonJS / ES Module 配置；停用定时任务后的旧 tick 不再继续触发。

## 工程实测

如意 + `DeepSeek V4.1 Flash` 在 SWE-bench Pro V2 HARD-51 的本地单次评测中 **44/51 题通过（86.27%）**，模型 API 费用估算 **¥42.15**，墙钟时间 **6:20:27**。对照官方 **Astra + Codex 90.20%**、**Sonnet 5 + Claude Code 88.20%**，分别相差 3.93 和 1.93 个百分点。官方 Sonnet 5.5 的 70.59% 条目使用 mini-swe-agent。

评测运行于 2026-10-15 的如意 **3.0.0 构建**，本版随附数据发布，未宣称 3.0.1 重新跑分。不同模型与框架的组合对照展示了工程交付能力，不能单独证明 harness 的因果优势。[协议、费用与全部逐题数据](https://github.com/wangzhe04/ruyi-workbench-oss/blob/v3.0.1/docs/benchmarks/hard51-2026-10-15/README.md) · [官方 HARD 榜单](https://labs.scale.com/leaderboard/swe_bench_pro_public_v2?tab=hard)

## English

Ruyi 3.0.1 brings together the fixes merged since 3.0.0: more reliable continuation after compaction and cross-chat reading, clearer crew monitoring and toolbox navigation, live-agent discovery, explicit follow-up runs and final-message delivery receipts. It also fixes steward protocol switching and new conversations, late-response draft races, deleted-session agent writes, project-aware JavaScript syntax checks, image-batch delivery and disabled scheduler ticks. Native media inspection and visual file reading provide more structured evidence for deliverables.

The release publishes a local SWE-bench Pro V2 HARD-51 (51-task hard subset) result: **Ruyi + DeepSeek V4.1 Flash, 44/51 resolved (86.27%), estimated model API charges CNY 42.15, wall time 6:20:27**. The evaluated runtime was a **3.0.0 build on 2026-10-15**, not a re-run of 3.0.1. It was 3.93 percentage points behind the official Astra + Codex result and 1.93 behind Sonnet 5 + Claude Code. Sonnet 5.5's official entry uses mini-swe-agent. These model–harness comparisons do not isolate harness causality. [Protocol and all task summaries](https://github.com/wangzhe04/ruyi-workbench-oss/blob/v3.0.1/docs/benchmarks/hard51-2026-10-15/README_EN.md).

Choose Full for the verified offline ACC/Python/OCR payload, or Slim for the workbench with its desktop shell and bundled Node. Extract completely to a short path and launch `Start-Workbench.cmd` or `RuyiDesktop.exe`. Upgrade into a new directory and keep your existing data directory.
