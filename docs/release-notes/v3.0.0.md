# 如意 Ruyi 3.0

**让它去办。你来拍板。**

今天，我们正式发布如意 Ruyi 3.0。

如意是一个开源、本地优先的 Windows AI 工作台。它把「和模型聊天」变成「让模型替你把事办完」：整理文件、运行脚本、处理 Word / Excel / PPT、操作桌面，或者叫上一队子代理一起调研，都可以在同一个工作台里完成。接上本机或内网模型，没有外网也能用。

从上一个正式版 2.6.2 到 3.0，我们最想解决的是三件事：事情多了有人帮你盯，放手交办之后还能收得回来，办到哪一步始终说得清楚。

## 有位管家，替你盯着所有事

顶栏一键切换「管家」和「工作台」。工作台陪你做眼前的事，管家帮你看全局：哪些正在办、哪些等你决定、哪些已经收工，一眼就能看清。

你可以让管家开新线程、续办任务、安排优先级、设置定时任务。别的线程需要你时，它会递来一张不抢焦点的提醒卡。你按停的事，它不会擅自重开。

## 敢交给它，也留得住后悔的机会

3.0 提供五档权限，从「每步都问」到「全自动」，由你选择。新安装默认「智能自动」：日常低风险操作自己办，需要你决定时再停下来。

支持的文件改动会留下检查点，可以撤销一处，也可以让对话和文件一起回到前一轮。你撤销以后，模型也会知道。无法自动撤销的操作，会在确认时说明。

管家可以在严格规则内代批部分操作；付款、格式化磁盘等底线动作不在代批范围。临时授权随时可以收回，做过什么也有记录可查。

## 办到哪一步，就说到哪一步

输入框上方会告诉你：现在在做什么、在等什么。失败会说明原因，没拿到回执就不会冒充办成了。

断网时用到旧资料，会标明是缓存；费用估算会明确标注，不当作实际扣费。机器检查、人工复核和模型自报完成，也会区分来源。

## 一个人，也能叫上一支班组

一句「深度调研一下」，就能让多个子代理分工协作。内置八套模板，覆盖调研、代码审查、排查问题、方案比较、文档和数据分析等任务，协作进度可以在「班组」画布上看到。

子代理可以在后台继续工作，你照常聊天；完成后会交回结果。长任务中断后，涉及写文件或执行命令的步骤不会盲目重跑。

## 聊得更久，接得更广

长对话会先收起旧工具输出，需要时还能找回原文；多步任务有草稿本保存中间结论，减少重复阅读和来回解释。

现在可以直接连接 Anthropic Messages、OpenAI 兼容接口，也能用本机 Ollama、LM Studio 或内网模型。Agent CLI 支持 Claude Code 和 Kimi Code，同一线程切换引擎时可以续接上下文。

还有语音输入、定时任务、回复中的流程图、会话搜索，以及从 Claude Code、Codex、Kimi 导入配置和技能的迁移中心。语音转成文字后由你检查和发送，不会自动发出去。

## 下载与升级

适用于 **Windows 10 / 11（64 位）**，Apache-2.0 许可，免费开源。

| 下载 | 怎么选 |
|---|---|
| [Full 完整包](https://github.com/wangzhe04/ruyi-workbench-oss/releases/download/v3.0.0/Ruyi-v3.0.0-full.zip) | 需要桌面控制和 OCR，或准备带进内网使用，选这个。内含所需 Python 运行环境。 |
| [Slim 精简包](https://github.com/wangzhe04/ruyi-workbench-oss/releases/download/v3.0.0/Ruyi-v3.0.0-slim.zip) | 主要用聊天、文件和脚本等能力，想少下载一些，选这个。 |
| [SHA256SUMS.txt](https://github.com/wangzhe04/ruyi-workbench-oss/releases/download/v3.0.0/SHA256SUMS.txt) | 用于核对下载文件是否完整。 |

完整解压到短路径（例如 `C:\Ruyi`），再运行 `Start-Workbench.cmd`，或打开 `RuyiDesktop.exe`。模型需自行配置；使用云端模型时，相关内容会发送给所选服务商。

**从 2.x 或 3.0 预览版升级**：先关掉旧版，备份数据目录，再把新版完整包解压到新目录后启动。默认数据目录是 `~/.ruyi-workbench`；更早的 `~/.win-claude-workbench` 会在首次启动时迁移。旧安装目录先保留，需要回退时同时恢复升级前的数据备份。使用 Claude Code / Kimi 集成的用户，也请在迁移中心检查是否仍有指向旧安装的配置。

桌面窗口需要 WebView2；缺少时启动器可回落到浏览器。离线使用还需提前准备本机或内网模型。真实桌面、读屏和第三方 CLI 的兼容性会受环境影响；本次自动测试不代表已经完成独立安全审计或全面无障碍认证。

## English

Ruyi 3.0 is an open-source, local-first AI workbench for Windows. Give it a task and it can work with files, scripts, Office documents and the desktop, or bring in a team of sub-agents. With a local or intranet model, it works without internet access.

This release brings a steward to keep track of your tasks, five permission levels, file checkpoints and conversation rewind, clearer progress and completion receipts, and eight multi-agent workflow templates. Long conversations keep more useful context while folding away older tool output. Anthropic Messages joins OpenAI-compatible protocols, alongside Claude Code and Kimi Code integrations. Voice input, scheduled tasks, diagrams, local conversation search and a migration center round out the release.

Download **Full** for bundled desktop control, OCR and Python, or **Slim** for a smaller package. Both include the Node runtime. Extract completely to a short path such as `C:\Ruyi`, then run `Start-Workbench.cmd` or `RuyiDesktop.exe`. Windows 10 / 11 x64; Apache-2.0.

To upgrade from 2.x or a 3.0 preview, close Ruyi, back up your data directory, and extract the new package into a new folder. Keep the old installation and the data backup together for rollback. Check old CLI integration paths in the migration center. Models are configured separately; cloud models receive the content sent to them. Desktop and CLI compatibility depends on your environment. Automated regression testing does not constitute an independent security audit or comprehensive accessibility certification.
