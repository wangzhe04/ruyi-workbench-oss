# 如意 Ruyi 3.0

**让它去办。你来拍板。**

今天，我们正式发布如意 Ruyi 3.0。

如意是一个开源、本地优先的 Windows AI 工作台。它把「和模型聊天」变成「让模型替你把事办完」：整理文件、运行脚本、处理 Word / Excel / PPT、操作桌面，或者叫上一队子代理一起调研，都可以在同一个工作台里完成。接上本机或内网模型，没有外网也能用。

从上一个正式版 2.6.2 到 3.0，如意把过去几轮预览版的升级带到了同一张工作台上：有了替你盯全局的管家，有了可分工协作的班组，也把长对话、权限、语音和模型接入重新打磨了一遍。

我们最想解决的是三件事：**事情多了有人帮你盯，放手交办之后还能收得回来，办到哪一步始终说得清楚。**

## 先看几个变化

- **能做的事更多了。** 原生工具从 2.6.2 的 **61 个增加到 112 个**，覆盖文件、脚本、搜索、Git、子代理协作和管家管理。
- **长对话少背些包袱。** 在历史会话样本中，大段工具输出缩小了约 **81%**，需要时仍能找回完整原文。
- **打开后更快能用。** 本机启动测试中，从约 **3.3 秒缩短到 1.3 秒**。

这些性能数字来自开发过程中留存的测试样本，实际效果会随电脑、模型和任务变化。更重要的变化，是下面这些每天能用到的能力。

## 一台工作台，两种看法

顶栏一键切换「管家」和「工作台」。工作台陪你做眼前的事，管家帮你看全局：哪些正在办、哪些等你决定、哪些已经收工，一眼就能看清。你在工作台开的线程，管家也看得到，不用再交代一遍。

管家不只是一个通知面板。你可以让它**开新线程、续办任务、换工作区、调优先级、设置定时任务，或起草一套可复用的办事流程**。常用设置也能让它帮忙调整，需要确认的会递给你按钮，密钥等敏感设置仍由你掌握。

你正在忙时，别的线程需要你，会递来一张不抢焦点的提醒卡；你按停的事，它不会擅自重开。它做过什么、为什么这么做，都能查到。

## 交办可以更放心，做错也有机会退回来

3.0 提供五档权限：**每步都问、改文件不问、只做计划、智能自动、全自动**。新安装默认「智能自动」：日常低风险操作自己办，需要你决定时再停下来。你可以按任务调整，不用在「什么都问」和「完全放手」之间二选一。

支持的文件改动会留下检查点：改错一处，可以单独撤销；这一轮方向不对，可以让对话和文件一起回到前一轮。**你撤销以后，模型也会知道**，不会还按「已经改好了」继续往下做。无法自动撤销的操作，会在确认时说明。

需要它连续工作一会儿，还可以给一份临时授权，限制能碰的路径、能跑的命令、能否联网和有效时间，随时收回。管家也能在严格规则内代批部分操作；付款、格式化磁盘等底线动作不在代批范围。

## 办到哪一步，就说到哪一步

长任务不该只剩一个转圈。现在，输入框上方会告诉你：**正在做什么、做到哪了、在等什么**。

3.0 也更认真地区分「发起了」和「办成了」。工具没有返回确认，就会说没拿到结果；失败会说明原因，不知道的不会现编。机器检查过、人工复核过，还是模型自己报告完成，也会分别标清。

断网时用到旧资料，会告诉你这是多久前的缓存；费用按币种记录，估算会明确标注，不冒充实际账单。你能据此判断该继续、重试，还是接手。

## 一个人，也能叫上一支班组

一句「深度调研一下」，就能让多个子代理分工协作。内置八套模板：**深度研究、代码审计、编码与独立审查、Bug 定位、方案选型、文档生成、数据洞察、正反辩论**。

可以让不同代理分别搜集材料、提出方案、挑错和复核；写代码的人和审查的人也可以分开。谁在做什么、结果交给了谁，会实时画在「班组」画布上。并行改代码时，还可以隔离工作目录，减少互相覆盖。

子代理在后台工作，你照常聊天；完成后会交回一份精简结果，主会话可以接着往下办，不必塞进整段内部讨论。长任务中断后，涉及写文件或执行命令的步骤会等你确认，避免不知情地再做一遍。

## 长对话，少些遗忘和重复

过去，文件内容、命令输出和子代理讨论很容易把对话挤满。3.0 会先收起较早的大段工具输出，保留有用的摘要和原文入口；空间够用就停，不够时才进一步整理对话。

多步任务多了一本**会话草稿本**，用来保存中间结论、待办和注意事项。重复读取同一批文件时可以复用结果，模型也知道当前时间。你少解释几遍，它少从头做几遍。

## 接上你想用的模型，不同工作各有所长

3.0 新增 **Anthropic Messages**，与 OpenAI 兼容接口的 Chat Completions、Responses 并列。官方服务、兼容网关、本机 Ollama / LM Studio、内网模型，都能按自己的环境接入。

Agent CLI 可以选择 **Claude Code 或 Kimi Code**；同一线程切换引擎时，可以续接已有上下文。

主对话、管家、子代理和长对话摘要，也能分别选择模型。需要推敲的工作交给强模型，简单整理交给快模型，在一处管理，不必到处改配置。

## 日常使用，也多了这些顺手的事

- **说出来，先变成草稿。** 语音边说边出字，句尾自动纠错；有常用术语词库，也能从你的手动修改中学习。支持本地识别，文字由你检查后发送，不会自动发出去。
- **事情可以约好时间再办。** 每天、每周、每月或自定义时间，都能安排。可以只提醒、不调用模型，也可以到点跑一个任务；错过了会说明是补跑还是跳过。
- **流程和计划直接画出来。** 回复里可以显示流程图、时序图、甘特图，跟随亮暗主题切换。
- **旧对话更好找，记忆由你定。** 会话正文可以在本机搜索，拼错也能找；记忆经你确认后才保存，还能限定适用范围和到期时间。
- **换过来，少重配一遍。** 迁移中心可以从 Claude Code、Codex、Kimi 导入指令、MCP 和技能，也能帮老版本如意更新安装路径。首次启动有欢迎向导，体检和帮助手册都能在应用里查看。

## 仍然是你电脑上的工作台

如意默认只在本机提供服务，零遥测。接上本机或内网模型，可以离线工作；使用云端模型时，相关内容会发送给你选择的服务商。

3.0 还经过多轮本机安全加固，补强了凭据保护、文件访问和自动执行的边界。重要操作按所选权限档位处理，记录可查，敏感信息会脱敏。Full 包带齐桌面控制、Python 和 OCR 环境，Slim 则保留更小的下载体积。

适用于 **Windows 10 / 11（64 位）**，Apache-2.0 许可，免费开源。

完整解压到短路径（例如 `C:\Ruyi`），再运行 `Start-Workbench.cmd`，或打开 `RuyiDesktop.exe`。模型需自行配置；使用云端模型时，相关内容会发送给所选服务商。

**从 2.x 或 3.0 预览版升级**：先关掉旧版，备份数据目录，再把新版完整包解压到新目录后启动。默认数据目录是 `~/.ruyi-workbench`；更早的 `~/.win-claude-workbench` 会在首次启动时迁移。旧安装目录先保留，需要回退时同时恢复升级前的数据备份。使用 Claude Code / Kimi 集成的用户，也请在迁移中心检查是否仍有指向旧安装的配置。

桌面窗口需要 WebView2；缺少时启动器可回落到浏览器。离线使用还需提前准备本机或内网模型。真实桌面、读屏和第三方 CLI 的兼容性会受环境影响；本次自动测试不代表已经完成独立安全审计或全面无障碍认证。

## English

Ruyi 3.0 is an open-source, local-first AI workbench for Windows. Give it a task and it can work with files, scripts, Office documents and the desktop, or bring in a team of sub-agents. With a local or intranet model, it works without internet access.

Since the last stable release, 2.6.2, native tools have grown from **61 to 112**. Recorded development samples show **81% smaller historical tool output**, with the original still retrievable, and local startup improving from about **3.3 to 1.3 seconds**. Performance depends on your machine, model and task.

- **One workbench, two views.** The steward tracks work across threads, brings you quiet reminders, and can open or continue tasks, change workspaces and priorities, and arrange schedules. The workbench remains the place for hands-on work.
- **More control over delegation.** Five permission levels, Smart auto by default for new installs, file checkpoints, conversation rewind and revocable temporary grants. After an undo, the model is told what changed. Supported file changes can be rolled back; irreversible operations are identified when asking for approval.
- **Clearer progress and more honest results.** See what is happening and what is waiting. A request without a completion receipt is not reported as done. Cached information, estimated costs and different sources of verification are labelled.
- **A team when you need one.** Eight templates cover research, code review, coding with independent review, debugging, option comparison, documentation, data analysis and debate. Follow collaboration on the team canvas while sub-agents work in the background and return concise results.
- **Longer conversations with less repetition.** Older tool output folds away before stronger summarization is needed. A session scratchpad keeps intermediate findings, and repeated file reads can reuse results.
- **More choice of models.** Anthropic Messages joins OpenAI-compatible Chat Completions and Responses. Use local or intranet models, Claude Code or Kimi Code, and choose separate models for the main conversation, steward, sub-agents and summaries.
- **Useful everyday additions.** Voice drafts with corrections, recurring reminders or tasks, diagrams in replies, local conversation search, user-confirmed memories, and a migration center for instructions, MCP and skills from other tools.

Download **Full** for bundled desktop control, OCR and Python, or **Slim** for a smaller package. Both include the Node runtime. Extract completely to a short path such as `C:\Ruyi`, then run `Start-Workbench.cmd` or `RuyiDesktop.exe`. Windows 10 / 11 x64; Apache-2.0.

To upgrade from 2.x or a 3.0 preview, close Ruyi, back up your data directory, and extract the new package into a new folder. Keep the old installation and the data backup together for rollback. Check old CLI integration paths in the migration center. Models are configured separately; cloud models receive the content sent to them. Desktop and CLI compatibility depends on your environment. Automated regression testing does not constitute an independent security audit or comprehensive accessibility certification.
