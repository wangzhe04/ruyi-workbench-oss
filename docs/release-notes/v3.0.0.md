今天，我们正式发布如意 Ruyi 3.0。
如意是一个开源、本地优先的 Windows AI 工作台。它把「和模型聊天」变成「让模型替你把事办完」：读写文件、跑脚本、操作 Word / Excel / PPT 和桌面、派一队子代理去调研，都在你自己的电脑上完成，离线也能用。
3.0 是如意迄今最大的一次升级。距上一个正式版 2.6.2，它合入了第 107–137 波迭代与 40 余个 PR：多了一位替你盯全局的管家，多了一套让 AI 敢放手的可撤销机制，也把「诚实」做进了工作台的底座。
【3.0 的进步】
和 2.6.2 相比：
· 原生工具：62 个 → 112 个 · 长对话的真实上下文占用：下降 81%（大段工具输出缩成摘要，原件随时逐字节回读） · 上下文摘要的质量门通过率：77.8% → 88.9%，成本反而下降约 30% · 工具阶段耗时：下降约 64%（工具结果缓存与追加式工具表） · 记忆召回准确率（Recall@3）：90% → 95% · 冷启动到可用：约 3.3 秒 → 约 1.2 秒 · 大量线程时的待处理列表：快约 8 倍 · 失败原因分类：12 类 → 32 类，表里没有的如实说「未知」，不让模型现编 · 子代理的编排原文不再塞进主会话（此前最多 6 万字），主会话只收一份精简交付 · 质量：488 件离线端到端测试、222 个单元测试套件，Windows CI 全量回归
【一、一台工作台，两种看法】
3.0 把「管家」和「工作台」合进同一台工作台，顶栏一枚分段钮切换。管家替你盯全局，工作台陪你干细活。
管家看得见、不插手。你在工作台开的线程，管家都看得到，按你在不在场决定要不要出声；别的线程出了事，它只弹一张不抢焦点的「安静卡」。状态、收件箱和进度秒级同步。
每条线程只有一个状态：交办中、进行中、需要你、已收工、已停工。几件在跑、几件等你，一眼看清。
管家能办事，也守规矩： · 能替你开线程、续办、换工作区、调优先级、建定时任务、起草 Playbook · 128 项设置分三档：33 项直接生效，95 项等你点头，密钥、数据目录、命令放行这类 40 项永远不经管家 · 能自己搜网页、读文件；但一个回合里只要读过外部内容，这一回合的所有写动作都降级成提议 · 你按停的线程，它不会自己重开 · 做过的每件事都记进行动流水：依据、权限、花费、能不能撤销
能代批的，按规矩批。在「智能自动」档，线程停下来请示时，管家可以替你批准，但要十道闸全部通过：命令原文完整可见、没有拼接和编码构造、删除目标只限相对路径、写明理由、每小时最多 6 次。付款转账、格式化分区、改注册表与防火墙、关机重启、对外发送这些底线动作，管家永远不代批。
【二、可撤销的行动力】
「让 AI 动手」的前提是「动错了能收回来」。
· 五档安全模式：每步都问、改文件不问、只做计划、智能自动、全自动；新装默认智能自动，低风险自己办，高风险先问你 · 工具三级：只读、修改、执行；执行级操作永远不能被持久放行 · 文件检查点：写、改、删、移动之前先存改前状态，可以逐条撤销，也可以整轮回滚；做不到撤销的，弹窗上直接写着「无法自动撤销」 · 对话回溯：把线程拨回任意一轮，对话和文件一起回去 · 撤销之后，模型也知道：下一轮不会再按「已改好」的样子接着干 · 自主性授权书：签一张比当前权限更窄的临时授权，路径、命令、联网、次数、有效期都能限定，随时撤销 · 审计时间线：每次工具调用、每次权限决定都有记录，密钥一律脱敏
【三、只认回执的诚实底座】
· 只有回执才算数：拿不到回执，就如实说「我发起了，但没拿到回执」 · 失败说得出原因：取自工作台自己的 32 类分类表 · 验收说得出是谁说的：机器检查、人工复核、自报完成，各标来源 · 旧资料会标出来：断网时回落离线缓存，工具卡上印「缓存 · N 天前抓的」 · 成本不虚报：分币种逐笔记账，估算一律注明「非实际扣费」
【四、一个人，一支班组】
一句「深度调研一下」，如意会派出一队各司其职的子代理，并在「班组」画布上实时画出协作图。
· 8 套内置模板：深度研究、代码审计、编码与独立审查、Bug 定位、方案选型、文档生成、数据洞察、正反辩论 · 10 种角色、5 种质量门，其中投票与去重是确定性算法，不花 token · 资源租约防死锁，Git worktree 隔离并行改文件 · 子代理可以在后台跑，主会话照常对话；跑完后自动叫醒主会话接着干 · 长任务崩溃恢复：执行过命令或写过文件的节点一律停下等你确认，绝不盲目重放不可逆的副作用
【五、长会话，不失忆】
· 不再是黑盒：输入框上方常驻一行，说清现在在干什么、干到哪了、在等什么 · 分级压缩，先轻后重：先折叠旧工具结果，不花钱、原件可回读；够用就停，不够才做摘要 · 按缓存账装载工具：中途补装工具会让提示缓存命中率从 97% 掉到 3%，3.0 改成一次装齐 · 模型知道现在几点；新增会话草稿本，多步任务的中间结论不会丢
【六、接上任何一种头脑】
· 新增 Anthropic Messages 协议，与 OpenAI 兼容（Chat Completions / Responses）并列，官方与国产、内网的兼容网关都能直接接 · 本机 Ollama、LM Studio 免密钥，也能指向内网 vLLM · Agent CLI 可选 Claude Code 或 Kimi Code，每种引擎都知道自己运行在如意里 · 同一条线程换引擎，上下文自动续接 · 对话主模型、管家、强 / 快两档、子代理、压缩各用哪个模型，一张表管完
【七、更多新能力】
· 语音输入：边说边出字，句尾自动改错，本地识别 CPU 就能跑，从不自动发送；语音词库内置 472 条常用术语，还会从你手改的字里学，比如「刀客 → Docker」 · 定时任务：每天、每周、每月或 cron；到点只提醒（不花钱）或跑一个回合；错过了就如实标「补跑」或「跳过了」 · 回复里直接成图：Mermaid 流程图、时序图、甘特图，跟着亮暗主题换色 · 会话正文搜索：拼错了也找得到，全在本机，摘录先脱敏 · 记忆：由你确认才入库，带到期日和作用域，一次可提议三条 · 迁移中心：从 Claude Code、Codex、Kimi 导入全局指令、MCP 与技能，老版本如意一键迁移 · 上手更省心：六步欢迎向导，体检结果说人话，帮助手册在应用内直接读
【八、本地优先，安全为先】
· 服务只监听 127.0.0.1，零遥测；页面凭据握手下发，Host 白名单防 DNS 重绑定 · 联网工具拒绝私网与回环地址；数据目录里的密钥对文件工具双向拒绝；API 响应里的密钥一律掩码 · 3.0 系统性加固了本机安全：修复 4 处本机泄密面，补强智能自动档对经脚本联网、持久化与改系统写法的拦截 · 离线包分 Full（含桌面控制、CPython 与 OCR）与 Slim，内网解压即用，全部文件进 SHA-256 清单
