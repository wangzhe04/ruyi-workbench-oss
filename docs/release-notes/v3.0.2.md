# 如意 Ruyi 3.0.2 · 2026-11-18

3.0.2 基于 3.0.1，修复使用 Anthropic Messages 协议时的两个问题。

- **连续对话的缓存。** 流式 Claude 请求会将用户正文与本轮临时提示分开，服务商可以在下一轮复用相同的前缀。项目说明或模型目录发生变化时，下一次工具循环请求会使用新内容。
- **兼容网关的工具调用。** 网关明确拒绝 `cache_control` 时，如意会移除缓存标记并重试一次，同时保留工具定义、工具调用和结果。

## Windows 下载与升级

下载 `Ruyi-v3.0.2-full.zip` 可获得带离线 ACC、Python、OCR 和浏览器依赖的完整包。选择 `Ruyi-v3.0.2-slim.zip` 可仅安装工作台、桌面壳与自带 Node。两个压缩包的 SHA-256 见 `Ruyi-v3.0.2-SHA256SUMS.txt`。

请将压缩包完整解压到新目录，运行 `Start-Workbench.cmd` 或 `RuyiDesktop.exe`，沿用原有数据目录。

## English

Ruyi 3.0.2 is a patch for 3.0.1. Streamed Claude requests now keep the user’s message separate from temporary instructions so the provider can reuse a stable prefix across turns. Changes to project references and the model catalog take effect on the next tool iteration. When an Anthropic-compatible gateway explicitly rejects cache markers, Ruyi retries once with those markers removed and keeps the tools and their results.

Both Windows ZIPs include the desktop shell and Node. Full also bundles the offline ACC, Python, OCR and browser dependencies. Extract into a new directory, keep your existing data directory and launch `Start-Workbench.cmd` or `RuyiDesktop.exe`.
