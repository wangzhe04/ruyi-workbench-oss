## 目标与默认范围

保留 Node 后端、Web 前端、Agent 协议与业务状态，新增 Mac 平台实现；继续维护 Windows，避免长期复制两套业务源码。先交付浏览器内可用的工作台，再交付独立 App、桌面自动化及离线发行包。

估算默认：Apple Silicon 原生 arm64、拟以 macOS 14 为最低版本，验证最低版本及交付时选定的较新版本；P0 保留 macOS 14 为目标，最低版本运行仍待验证。本机 arm64/macOS 27 的探针支持 AppKit + WKWebView、Node 24、Python 3.12 路线；正式 Swift 构建还需匹配 SDK。详见 [v1 决策](11-P0-DECISIONS.md)，**不把目标版本写成已验证兼容**。Intel、Mac App Store、任意 Windows 软件兼容不包含在主估算内。
