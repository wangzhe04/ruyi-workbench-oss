# P1 路径匹配与遍历取消

2026-11-03，macOS 27.0.1 arm64、Node 24.15.0。基线 `0a430880`，工作树未提交，P1 保持进行中。

## 实现

路径 matcher 与内容扫描共用 closeSearchWorker，在 1 秒预算内等待 terminate，并核对 threadId。路径 matcher 的 close 幂等且可等待，能结束待决 match。永久 error/exit 监听处理批次之间发生的错误和退出。

walkFiles 在文件系统初始化之后才创建 matcher，finally 等待关闭并传播不完整退出。遍历、匹配结果处理和文件元数据读取之间检查取消。file_list、glob、project_snapshot 将 ctx.signal 传入，在取消或未确认退出时返回明确失败。

正常路径正则超时继续返回原有截断/时间预算信息；取消时不发布部分文件列表。已确认线程退出后的终止调用异常不被误报为活跃 worker 清理不完整。
