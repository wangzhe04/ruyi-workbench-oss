# P1 原子写入取消与失败恢复

2026-11-03，macOS 27.0.1 arm64，Node 24.15.0，HEAD `0a430880` 的未提交工作区。

## 实现

FileTextIo.writeFileAtomic 接收 signal。file_write 与 file_edit 将请求取消信号传入。临时文件阶段、rename 重试前以及所有原地写回退前检查取消。取消返回 aborted，并等待临时文件清理尝试结束。rename 或原地写成功后保留真实成功结果。

原地 writeFile 失败可能已截断或部分写入目标。此类异常带 targetMayBeModified，保留实际写错误。file_write、file_edit、archive_zip 据此保留本次检查点，并返回 checkpointRetained、checkpointWarn 和部分写入提示。仅未触及目标的失败撤掉本次 entrySeq，早期检查点保留。
