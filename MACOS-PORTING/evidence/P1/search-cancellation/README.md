# P1 文件与文档搜索取消

2026-11-03，macOS 27.0.1 arm64、Node 24.15.0。基线 `0a430880`，工作树未提交，P1 保持进行中。

## 实现

file_search 与 docs_search 将 ctx.signal 传入遍历和内容正则 worker。预取消跳过 worker；遍历在后续目录/条目处理前检查取消；内容 worker 收到取消后终止，并等待退出确认。确认预算为 1 秒，未确认且 threadId 仍存活时返回 worker_cleanup_incomplete。

取消或清理不完整时清除部分匹配、编码信息与隐私源数据，停止后续字面重试与结果发布。正常超时仍返回原 timedOut/部分结果语义，但先确认 worker 退出。终止调用失败时，已退出的 threadId 可作为完成证据。

共享 rg 版本探针有服务级 capability-probe owner，单个搜索只取消自己的等待，其他消费者可继续。等待器始终消费共同 promise 的后续成功或失败，并移除 abort listener。服务级探针沿用其原有有界监督生命周期。
