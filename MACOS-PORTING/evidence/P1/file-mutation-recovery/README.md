# P1 文件变更失败恢复

2026-11-03，macOS 27.0.1 arm64，Node 24.15.0。HEAD `0a430880`，本批未提交。

## 实现

- 删除、复制、移动在检查点完成后、提交前检查取消。复制与移动在 mkdir 后再检查。跨卷移动尚未开始复制时可以取消，已经进入 copy/unlink 提交段则完成并报告实际结果。
- copyFile 可能部分写入后失败。file_copy 和 EXDEV 移动保留本次恢复记录，报告 partial、targetMayBeModified、checkpointRetained 及检查点警告。源 unlink 失败也保留两侧快照。
- 纯大小写改名经临时路径中转，恢复原名失败时报告 recoveryPath 和 restoreError，并保留源文件快照。
- copy 准备失败仅按本次 entrySeq 删除未提交记录，同一路径早期记录保留。
- 源文件 stat 移到写锁内，排队后的别名判断使用最新身份。
