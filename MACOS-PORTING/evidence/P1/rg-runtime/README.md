# P1 Mac rg 搜索执行监督

2026-11-03，macOS 27.0.1 arm64、Node 24.15.0。基线 `0a430880`，工作树未提交，P1 保持进行中。

## 实现

Mac 的异步 rg 版本探针、主搜索和高字节文件补扫统一使用 ProcessRuntime.capture，登记 file-search owner 并继承工具调用身份。预算分别为版本 4 秒、主搜索默认 10 秒、补扫 8 秒。stdout/stderr 分别受相同的单流字节预算约束，版本 64KiB、主搜索 32000000 字节、补扫 8000000 字节；UTF-8 在完整捕获后解码。

取消和超时停止受管执行，并最多等待 1500ms 清理确认。只有确认清理后的普通错误、超时或输出超限才允许主搜索回退 JS。helper 缺失或同步启动前失败没有启动外部进程，允许安全使用 JS；异步探针不会因此污染 rg 缓存。

主搜索与补扫的清理不完整、输出管道不完整、取消均中止本次搜索。补扫增强的错误捕获保留这些失败，file_search 返回明确错误和清理范围。预取消在冷缓存探针之前拒绝。Windows 执行路径继续使用既有 spawn 逻辑，NDJSON 解析作为共享闭包。
