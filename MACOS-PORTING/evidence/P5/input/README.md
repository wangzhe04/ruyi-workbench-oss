# P5-02 窗口与剪贴板首批实现

2026-11-10，基线 `0de6d03e`，分支 `codex/p5-macos-automation`。当前 macOS 27.0.1 arm64、Node 24.15.0、Python 3.12.10、SDK 15.2，编译目标为 macOS 14.0。P5-02 继续进行，键盘、Cmd 粘贴、中文输入、鼠标、滚轮和应用启动留在后续开发范围。

## 当前入口与契约

- ACC Mac 后端接入 `list_windows`、`get_active_window`、聚焦、移动、缩放、最大化、最小化、关闭窗口，以及文本和图片剪贴板读写。发现目录根据当前授权、锁屏和 helper 状态分族刷新。
- 每个 ACC MCP 拥有一个串行 JSONL 原生工作进程。窗口 target 包含工作进程私有 UUID ref、CG ID、PID、进程启动身份和观察时的逻辑点边界。引用上限 128，空闲有效期五分钟。过期、跨进程和重启后的引用需要重新观察。
- 首次操作通过完整有界 AXWindows 枚举核对标题与边界并建立唯一 AX 绑定。后续用 CFEqual 核对同一 AX 元素仍属于原进程，最小化期间继续保留此引用。窗口位置变化使旧几何观察失效。
- 聚焦核验真实前台应用及精确 AX 焦点窗口，移动和缩放核验 AX 与 CG 的实际结果。关闭操作核验原窗口离开应用 AXWindows，进程结束另需启动身份明确变化或 ESRCH 证据。
- 原生输入帧最多 64 KiB，响应最多 68 MiB，单帧原生截止 12 秒，Python 截止 15 秒。通信不确定时回收工作进程并返回动作状态，调用层保留 `acted`、`action_sent`、`outcome` 等字段。重连后的新请求重新分配窗口引用。
- 剪贴板显式写入前在原生内存中保存所有原格式，容量为 32 MiB。写入失败时仅在变更计数仍属于本次写入的情况下尝试恢复。图片读写使用统一 sRGB PNG 编码，允许合法黑色图片。保存路径复用既有路径保护与原子写入。

## 独立审查与修正

独立审查要求精确核对 AX 焦点、完整枚举后才认定唯一匹配、拒绝布尔和小数身份、保留部分动作及剪贴板恢复元数据。这些修正已接入。后续审查发现最小化窗口关闭假成功及动作后身份变化元数据缺失，已改为 AX 成员验证和不确定动作结果。进程身份查询失败使用保守结果，只有明确进程不存在时才判定结束。

历史失败日志保留。早期一次性 helper 无法在 CG 清单缺席时恢复最小化窗口，已引入常驻 AX 引用。首轮常驻实现被伪造目标请求错误地删除有效绑定，已分离请求字段不匹配与真实进程身份失效。最小化 AX 可能报告 Dock 几何，现通过原 AX 成员身份验证。重叠窗口首轮观察后发生几何变化，夹具增加 300ms 初始化阶段后报告并轮询 CG 观察，生产代码仍拒绝变化后的几何。
